# TG Автопостер — итоги груминга

Дата: 2026-11-04. Основа — код [tg-autocomment](https://github.com/NotoBoto/tg-autocomment)
(принадлежит автору, копируется свободно).

## Что делает программа

Пользователь вписывает темы (одна строка — одна тема). По каждой теме нейросеть пишет текст поста
по «промпту текста» и рисует картинку по «промпту картинки». Черновик показывается пользователю:
его можно подтвердить, отменить, поправить вручную или перегенерировать текст / картинку
с пожеланием. Подтверждённый пост публикуется в канал сразу или ставится отложенным постом
по расписанию, которое настраивается в программе.

## Принятые решения

| # | Вопрос | Решение |
|---|---|---|
| 1 | Интерфейс | Десктоп-приложение Windows как у автокомментатора: customtkinter, трей, автозапуск, установщик, автообновление |
| 2 | От чьего имени | От аккаунта пользователя (Telethon). Отложенные посты — нативные Telegram (`schedule_date`): выходят, даже если компьютер выключен |
| 3 | Каналы | Профили как в автокомментаторе: у профиля свой аккаунт, канал(ы), промпты, нейросеть, расписание |
| 4 | Нейросети | Все способы автокомментатора для текста; для картинок — все, что умеют генерировать (см. ниже) |
| 5 | Ввод тем | Списком: одна строка — одна тема, по каждой создаётся черновик |
| 6 | Длина и оформление | Настраиваются в программе и передаются в промпт; программа дополнительно проверяет лимит Telegram |
| 7 | Перегенерация картинки | Оба варианта: «нарисовать заново» и «поправить текущую» |
| 8 | Репозиторий | `NotoBoto/tg-autopost` (пока приватный — сделать публичным до первого релиза, иначе автообновление не увидит релизы) |

## Нейросети

**Текст** — все способы из автокомментатора, код переносится: Z.ai, Claude Code, Antigravity,
Claude API, Gemini API, ChatGPT (Codex), OpenAI API, своя модель (OpenAI-совместимая).
«Без нейросети» не нужен.

**Картинка** — выбирается отдельно от текста (в профиле может быть Claude для текста и Codex для картинки):

| Способ | Генерация | Правка текущей | Проверить |
|---|---|---|---|
| ChatGPT (Codex) по подписке | `image_generation` в Codex CLI | `--image` + пожелание | как Codex отдаёт файл, расход лимита |
| OpenAI API | Images API (`gpt-image-*`) | `images.edit` | — |
| Gemini API | модели Gemini Image / Imagen | Gemini Image с картинкой на входе | — |
| Z.ai | их image-модели | — | есть ли бесплатные, работает ли из РФ |
| Своя модель | `/v1/images/generations`, если сервер умеет | — | — |
| Antigravity | — | — | умеет ли CLI картинки |
| Без генерации | своя картинка из папки («колода», как в автокомментаторе) или пост без картинки | — | — |

Claude картинки не генерирует — для текста доступен, для картинки нет.

## Черновик: жизненный цикл

```
тема → [пишется текст] → [рисуется картинка] → на проверке
на проверке → поправить текст вручную / сменить картинку на свою
            → перегенерировать текст с пожеланием
            → картинка: «нарисовать заново» или «поправить текущую» с пожеланием
            → отменить → в «Отменённые» (можно вернуть)
            → подтвердить → опубликовать сейчас | в ближайший свободный слот | на своё время
запланирован → сменить время / опубликовать сейчас / снять с публикации (вернуть в проверку)
опубликован → в «Опубликовано» со ссылкой на пост
```

Черновики и очередь хранятся на диске — переживают перезапуск и обновление.

## Промпты

Два промпта на профиль, с подстановками:

- **Промпт текста:** `{тема}`, `{пожелание}`, `{длина}`, `{оформление}`, `{эмодзи}`, `{хэштеги}`,
  `{подпись}`, `{прошлые посты}` (несколько последних — чтобы не повторяться).
- **Промпт картинки:** `{тема}`, `{текст поста}`, `{пожелание}`, `{стиль}`, `{формат}` (квадрат / 16:9 / 4:5).

Варианты `{{a | b | c}}` — как в автокомментаторе.

## Настройки поста (п. 6)

- Длина: максимум знаков (по умолчанию 1024 — лимит подписи к фото; 4096 для Premium или без картинки).
- Если текст длиннее подписи: попросить нейросеть сократить / отправить картинку и текст отдельно.
- Оформление: без форматирования / жирный и курсив / с ссылками (публикация в HTML-разметке Telegram).
- Эмодзи: нет / немного / много. Хэштеги: нет / список своих / пусть подберёт нейросеть.
- Подпись в конце поста (например ссылка на канал) — добавляется программой, а не нейросетью.

## Расписание

На профиль (канал):

- **Слоты:** дни недели × времена (например пн–пт 10:00, 19:00; сб–вс 12:00).
- **Или интервал:** каждые N часов в окне с ЧЧ:ММ до ЧЧ:ММ.
- Случайный сдвиг ± N минут, чтобы посты не выходили секунда в секунду.
- Минимальный промежуток между постами.
- «В ближайший свободный слот» учитывает уже запланированные посты, в том числе поставленные
  в отложку вручную в Telegram (читаем список отложенных канала).
- Пачка подтверждённых тем раскладывается по слотам подряд.

## Окно

Строка «Аккаунт» (профили) и вкладки:

- **Темы** — поле «одна строка — одна тема», кнопка «Сгенерировать».
- **Проверка** — карточки черновиков: картинка, редактируемый текст, кнопки действий, поле пожелания.
- **Запланировано** — отложенные посты с временем; сменить время, опубликовать сейчас, снять.
- **Опубликовано** — история со ссылками, поиск, выгрузка.
- **Промпты** — текст и картинка.
- **Расписание.**
- **Настройки** — Telegram, канал(ы), нейросеть для текста, нейросеть для картинки, настройки поста, программа.
- **Журнал.**

## Что переносим из автокомментатора

Без изменений: вход в Telegram (QR / телефон / 2FA), прокси и VPN, встроенный API-ключ Telegram,
все способы подключения к нейросетям с установкой и входом, профили, трей, автозапуск,
одна копия программы, журнал, `updater.py`, `build.py`, `installer.iss`, `release.yml`.

Убираем: слежение за каналами, комментирование, пасты, заготовки, моментальный режим,
стоп-слова, отчёт по комментариям.

## План работ

1. **Каркас** — перенос кода, переименование (TG Autopost, папка `%APPDATA%\TG Autopost`,
   отдельный mutex и автозапуск, чтобы не конфликтовать с автокомментатором), вычистка лишнего.
2. **Модель данных** — черновик, его статусы и хранение; профиль с новыми полями.
3. **Генерация текста** — промпт с подстановками, все способы; настройки поста.
4. **Генерация картинок** — Codex и OpenAI API первыми, затем Gemini, Z.ai, своя модель; «заново» и «правка»;
   своя картинка.
5. **Вкладки «Темы» и «Проверка»** — ввод списка, карточки, все действия.
6. **Публикация** — сразу и отложенно через Telegram, проверка прав в канале, лимит подписи, HTML-разметка.
7. **Расписание** — настройки, подбор ближайшего слота, вкладка «Запланировано», синхронизация с отложкой Telegram.
8. **Опубликовано, README, сборка и первый релиз** — сделать репозиторий публичным перед релизом.

MVP — шаги 1–7 с картинками только через Codex и OpenAI API; остальные генераторы картинок — следом.

## Статус (2026-11-04)

Шаги 1–7 сделаны, в MVP вошли все генераторы картинок, а не только Codex и OpenAI. Отличия от плана:

- **Codex и картинки проверены:** на бесплатном тарифе ChatGPT инструмент `image_gen` в Codex недоступен.
  Генератор через Codex сделан (берёт файл из `~/.codex/generated_images`), но на бесплатном тарифе выдаёт
  понятную ошибку. Картинки по умолчанию — OpenAI API.
- Спойлеры (`<tg-spoiler>`) убраны из оформления: HTML-парсер Telethon их не поддерживает.
- Шаблон «каждые N часов» и «по дням недели» — оба режима расписания.

Проверено: 21 автотест (расписание, оформление поста, промпты, публикация и сверка отложенных
с имитацией Telegram, цепочка генерации), настоящая генерация текста через Codex, путь в окне
«тема → черновик → отмена → возврат». **Не проверено вживую:** вход в Telegram и публикация в настоящий
канал, генерация картинок через OpenAI / Gemini / Z.ai (нет ключей), сборка установщика.
