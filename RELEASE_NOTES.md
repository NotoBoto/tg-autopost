Первая версия TG Автопостера.

- Темы списком: одна строка — одна тема, по каждой нейросеть пишет текст и рисует картинку
- Проверка черновика: правка вручную, «поправить» и «написать заново» с пожеланием для текста и картинки, варианты картинок, своя картинка
- Публикация сразу, в ближайший свободный слот расписания или на своё время — родными отложенными постами Telegram
- Вкладка «Запланировано»: отложенные посты каналов из Telegram — перенести, опубликовать сейчас, снять
- Расписание по дням недели или «каждые N часов», случайный сдвиг и минимальный промежуток между постами
- Нейросети для текста — все способы из TG Автокомментатора; для картинок — OpenAI API, Gemini API, ChatGPT (Codex), Z.ai, своя модель, своя папка
- Настройки поста: длина, оформление, эмодзи, хэштеги, подпись канала
