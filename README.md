# TG Автопостер

Программа для Windows, которая ведёт Telegram-канал вместе с вами. Вы пишете темы постов. По каждой
нейросеть пишет текст и рисует картинку. Вы проверяете черновик: правите вручную, просите переписать
текст или перерисовать картинку с пожеланием. Потом публикуете сразу или ставите в отложенные посты
по своему расписанию.

## Как это работает

1. **Темы** — впишите темы, одна строка — одна тема, и нажмите «Сгенерировать посты».
2. **Проверка** — по каждой теме готов черновик:
   - текст можно править прямо в поле или попросить нейросеть: «✎ Поправить» (по пожеланию,
     например «короче», «веселее») или «↻ Написать заново»;
   - картинку — «↻ Нарисовать заново» с пожеланием или «✎ Поправить эту» (правит текущую),
     вернуться к прошлому варианту (◀ ▶), поставить свою или убрать;
   - **Опубликовать сейчас**, **В расписание** (ближайшее свободное время) или **на своё время**
     («19:30», «завтра 10:00», «07.11 19:30»), либо **Отменить**. Отменённые можно вернуть.
   - «Все готовые — в расписание» раскладывает все готовые черновики по свободным слотам разом.
3. **Запланировано** — отложенные посты каналов прямо из Telegram: и поставленные программой, и
   добавленные вручную. Их можно перенести, опубликовать сейчас или снять с отложенных.
   Отложенные посты — родные отложенные Telegram: они выйдут, даже если компьютер выключен.
4. **Опубликовано** — история со ссылками на посты, поиском и копированием текста.

### Если закончился лимит нейросети

Программа узнаёт ошибку лимита у любой нейросети и ставит очередь на паузу: остальные темы не
отправляются зря, а ждут — в списке у них «⏸ лимит · продолжу сегодня 15:05». Время сброса программа
берёт из ответа сервиса (Codex, Claude Code, Gemini, OpenAI, Claude API, Z.ai его сообщают); если
сервис не сказал — пробует через 15, 30, затем каждые 60 минут. В нужный момент очередь продолжается
сама, в том числе после перезапуска программы. Лимит на картинки не мешает тексту: текст готов,
картинка дорисуется после сброса — или поставьте свою.

Не хотите ждать — «↻ Повторить сейчас» над списком (там же повторяются черновики с обычными
ошибками) или смените нейросеть в «Настройках»: очередь сразу перейдёт к новой.

### Журнал

Во вкладке «Журнал» — что программа делала и что вы делали: какая тема ушла в работу, кто писал текст
и сколько это заняло, перегенерация с каким пожеланием, какой вариант картинки выбран, правки вручную,
отмена, возврат, удаление, публикация (сколько знаков, правлен ли текст, какая картинка, ссылка),
перенос и снятие отложенных, паузы и продолжение очереди по лимитам.

## Настройки

- **Telegram** — каналы, куда публиковать. Аккаунт должен быть админом канала с правом публикации.
  Вход по QR-коду или номеру телефона — при первом «▶ Запустить».
- **Нейросеть для текста** — все способы из TG Автокомментатора: Z.ai (бесплатно, без VPN),
  Claude Code и ChatGPT (Codex) по подписке, Antigravity, API-ключи Claude / Gemini / OpenAI,
  своя модель (LM Studio, Ollama…).
- **Картинка** — чем рисовать:
  - **OpenAI API** — модели gpt-image, по ключу, умеет править картинку;
  - **Gemini API** — Gemini Image (умеет править) или Imagen, по ключу;
  - **ChatGPT (Codex)** — по подписке, без ключа. Генерация картинок в Codex есть не на всех тарифах:
    на бесплатном её нет, программа так и скажет;
  - **Z.ai** — CogView, платно;
  - **Своя модель** — сервер с OpenAI-совместимым `/v1/images/generations`;
  - **Из папки** — ваши картинки по очереди без повторов;
  - **Без картинки**.

  Там же формат (квадрат, горизонтальная, вертикальная), стиль и таймаут.
- **Пост** — длина, оформление (без форматирования / жирный и курсив / + ссылки и цитаты), эмодзи,
  хэштеги (без, из своего списка, подбирает нейросеть), подпись в конце поста (её добавляет программа,
  можно со ссылкой), что делать с текстом длиннее подписи к картинке (1024 знака, у Premium — 4096):
  отправить картинку и текст отдельными сообщениями или не публиковать, пока не сократите.
  Эти настройки передаются нейросети в запросе.
- **Расписание** — времена публикаций по дням недели или «каждые N часов с … до …», случайный сдвиг
  ± минут и минимальный промежуток между постами. Слот считается занятым, если рядом уже стоит
  отложенный пост канала — свой или добавленный вручную. Внизу — ближайшие свободные времена.
- **Промпты** — промпт текста и промпт картинки. В них можно вставлять `{тема}`, `{пожелание}`,
  `{длина}`, `{оформление}`, `{эмодзи}`, `{хэштеги}`, `{прошлые посты}` (текст) и `{тема}`, `{текст поста}`,
  `{пожелание}`, `{стиль}`, `{формат}` (картинка). Чего в промпте нет — программа допишет в запрос сама.
  `{{вариант 1 | вариант 2}}` — к каждому посту подставится случайный вариант.

Несколько аккаунтов — «+ Добавить аккаунт»: у каждого профиля свои каналы, нейросети, промпты и
расписание. Трей, автозапуск с Windows, прокси и VPN, автообновление — как в TG Автокомментаторе.

Генерировать черновики можно без подключения к Telegram, публиковать — после «▶ Запустить».

## Запуск из исходников

Дважды щёлкнуть **`start.bat`**: нет Python — поставит через `winget`, нет библиотек — поставит
(вручную: `pip install -r requirements.txt`, затем `python app.py`). Данные лежат рядом с `app.py`.

Тесты: `pip install pytest`, затем `python -m pytest tests`.

## Где что лежит

| Файл | Что в нём |
|---|---|
| `app.py` | окно: вкладки, профили, трей, автозапуск, обновления |
| `engine.py` | движок профиля: Telegram, генерация черновиков, публикация, отложенные посты |
| `textgen.py` | нейросети для текста |
| `imagegen.py` | нейросети для картинок и картинки из папки |
| `drafts.py` | черновики и история (`drafts.json`, картинки — в `drafts/`) |
| `schedule.py` | расписание: ближайшее свободное время |
| `limits.py` | лимиты нейросетей: распознать исчерпанный лимит и время его сброса |
| `core.py` | настройки, промпты, оформление поста для Telegram, прокси, вход в CLI нейросетей; здесь `VERSION` |
| `updater.py`, `build.py`, `installer.iss`, `.github/workflows/release.yml` | обновления и сборка — как в TG Автокомментаторе |

Установленная версия хранит данные в `%APPDATA%\TG Autopost`. Файлы `*.session` — полный доступ к
аккаунту Telegram, никому их не передавайте.

## Выпуск версии

Как в TG Автокомментаторе: поменять `VERSION` в `core.py`, описать изменения в `RELEASE_NOTES.md`,
поставить тег `vX.Y.Z` и запушить его. Нужны секреты `TG_API_ID` и `TG_API_HASH` в настройках
репозитория. **Перед первым релизом сделайте репозиторий публичным** — иначе автообновление не
увидит релизы.
